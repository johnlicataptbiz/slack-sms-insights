# PT Biz SMS Insights User Guide

## Welcome to SMS Insights
SMS Insights is your comprehensive platform for SMS performance analytics, reporting, and team management. This guide covers key features and how to use them effectively.

### Getting Started
1. **Install the Slack App**: Add SMS Insights to your Slack workspace.
2. **Open Home Tab**: Click the SMS Insights app in Slack to view your personalized dashboard.
3. **Set Preferences**: Use `/settings` to customize your experience.

### Dashboard Overview
- **Personalized View**: Content tailored to your role (Admin, Manager, Setter).
- **Quick Actions**: Floating bar for common tasks.
- **Live Activity Feed**: Real-time updates on reports and events.
- **Progressive Loading**: Content loads dynamically with skeleton placeholders.

### Generating Reports
1. Use `/sms-report [date]` command.
2. Apply advanced filters for specific data.
3. Use drill-down to explore details.
4. Export in PDF, CSV, or Excel formats.

### Automated Reports
- Set up daily, weekly, or monthly schedules.
- Configure delivery to Slack channels or email.
- Manage schedules from the settings menu.

### Real-Time Monitoring
- Live KPI updates every few minutes.
- Custom alerts for performance thresholds.
- Trend analysis and visualizations.

### Team Management (Managers/Admins)
- View team performance metrics.
- Bulk actions for user management.
- Shared report annotations.

### Mobile Usage
- Optimized for Slack mobile app.
- Touch-friendly interfaces.
- Offline support with cached data.

### Troubleshooting
- Check the error dashboard for issues.
- Use `/help` for command reference.
- Contact support if needed.

For detailed API docs, visit [API Documentation](https://example.com/api-docs).

Happy reporting! 📊
